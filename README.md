# Windows 95 Web Simulation

Интерактивная веб-симуляция легендарной операционной системы **Microsoft Windows 95**, воссозданная на чистом **HTML, CSS и JavaScript** без использования сторонних фреймворков.

## Особенности и функционал

Проект воспроизводит классический пользовательский интерфейс и базовую логику работы системы:

### Рабочий стол и системный интерфейс
* **Экран загрузки (Boot Screen):** Интерактивный запуск системы с имитацией готовности диска `C:` и звуковым сопровождением.
* **Меню «Пуск» и панель задач:** Полноценная навигация по приложениям, системные часы и управление звуком.
* **Контекстное меню и файловая система:** Создание текстовых файлов (`.txt`) и точечных рисунков (`.bmp`), их открытие, просмотр свойств, удаление и перезагрузка интерфейса.
* **Защита от DevTools:** Встроенная пасхалка с предупреждением при попытке открыть инструменты разработчика (`F12`).

### Встроенные приложения
* **Мой компьютер:** Просмотр дисков (`Диск C:`, `Диск A: (3.5)`) и системных папок (включая папку `WINDOWS` с имитацией ошибки доступа).
* **Блокнот (Notepad):** Текстовый редактор с поддержкой создания, редактирования, сохранения изменений, загрузки файлов с устройства и скачивания готового документа.
* **Paint:** Графический редактор с инструментами кисти, ластика и очистки холста, а также возможностью загружать и сохранять изображения в формате **BMP**.
* **Калькулятор:** Классический калькулятор для базовых арифметических вычислений (с обработкой деления на ноль).
* **Сапёр (Minesweeper):** Классическая логическая игра со счётчиком мин, таймером и меню справки.
* **Windows Media Player:** Проигрыватель для воспроизведения видеофайлов, загруженных с устройства пользователя.
* **Радио:** Встроенный плеер с выбором онлайн-радиостанций.
* **Панель управления:**
  * *Экран:* Настройка яркости всего интерфейса в реальном времени.
  * *Система:* Полный сброс до заводских настроек с очисткой всех созданных файлов и перезагрузкой.
  * *О системе:* Информация о проекте и разработчике.

## Технологический стек

* **HTML5** — семантическая разметка окон, меню и элементов управления.
* **CSS3** — аутентичная пиксельная стилизация окон, кнопок, рамок и иконок в духе Windows 95.
* **Vanilla JavaScript (ES6+)** — управление окнами (перетаскивание, сворачивание, закрытие), работа с `localStorage` для сохранения файлов и настроек, логика игр и приложений.
