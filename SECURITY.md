# Политика безопасности (Security Policy)

## Поддерживаемые версии

Поскольку проект представляет собой клиентскую веб-симуляцию **Windows 95** на чистом HTML, CSS и JavaScript, обновления безопасности применяются исключительно к актуальной ветке репозитория.

| Версия | Статус поддержки |
| :--- | :--- |
| `main` (актуальная) | :white_check_mark: Поддерживается |
| Старые коммиты / форки | :x: Не поддерживаются |

## Архитектура безопасности и локальное хранение

* **Отсутствие серверной части:** Приложение полностью выполняется в браузере пользователя (`client-side`). Персональные данные не передаются на внешние серверы.
* **Локальное хранилище:** Созданные в симуляции файлы (текстовые документы, рисунки BMP) и настройки экрана сохраняются локально в браузере (например, в `localStorage` или `IndexedDB`). Пользователь может в любой момент очистить их через **Панель управления → Система → Сброс к заводским настройкам**.
* **Загрузка пользовательских файлов:** Загружаемые в *Блокнот*, *Paint* или *Windows Media Player* файлы обрабатываются локально в памяти браузера без загрузки в сеть.
